# 轻录屏使用说明

“轻录屏”是一款面向 macOS 与 Windows 的简洁录屏工具，支持全屏录制、区域录制、系统声音、麦克风、画质选择和全局快捷键。

## macOS 版本

应用位置：`dist/轻录屏.app`

首次使用需要在“系统设置 → 隐私与安全性”中允许：

1. 屏幕与系统音频录制
2. 麦克风（仅在勾选录制麦克风时需要）

授权后请使用 `Command + Q` 完全退出，再重新打开应用。

### 录制

- 划定区域：点击“选择区域并录制”，拖动红框调整位置和大小，然后确认。
- 全屏：选择“全屏”后开始录制。
- 录制过程中会显示计时、停止按钮和动态四角提示；这些提示不会进入视频。
- 标准画质适合分享；高清使用 H.264，适合日常录制；超清使用 ProRes 422 HQ MOV，适合代码、文字和演示文稿，但文件会明显更大。

### 快捷键

默认尝试 `Command + Space`。该组合通常被 Spotlight 占用，发生冲突时建议改用 `Command + Option + R`。

### 输出

标准和高清使用 H.264 MP4；超清使用 ProRes 422 HQ MOV。默认保存到“影片”目录，可在应用中修改。

## Windows 版本

Windows 项目位于 `Windows/ScreenFlowLite.Windows`，需要：

- Windows 10 1903 或更高版本
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- FFmpeg，并将 `ffmpeg.exe` 放到应用目录或加入系统 `PATH`

构建：

```powershell
cd Windows\ScreenFlowLite.Windows
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布结果位于 `bin\Release\net8.0-windows\win-x64\publish`。

## 隐私

轻录屏不上传录制内容。屏幕、系统声音和麦克风数据只在本机编码并保存。
